# 动效设计

原则 动效只用来演示功能 不做装饰 标题和文字不做入场动画

## 清单

| 位置 | 触发 | 效果 |
|---|---|---|
| 首屏 | 页面加载 | 标题 副标题 按钮 产品窗口依次出现 只此一次 |
| 首屏产品窗口 | 加载后 | 用户发消息 三步工作依次转圈打勾 最后产出文件 |
| 首屏产品窗口 | 滚动 | 从 0.94 放大到 1 |
| 浏览器场景 | 进入视野后循环 | 指针逐个填表 点保存 按钮变绿 |
| Bot 形象 | 随状态 | 等待静止 工作弹动且边缘有波纹 思考呼吸 等确认弹跳歪头 完成跳一下变笑眼 报错变红泄气发抖 状态之间连续过渡 |
| 头像选择器 | 用户点击 | 点 Bot 卡片选中 再点形状或颜色 头像即时更换 |
| 审批场景 | 用户点击 | 切换档位 三项权限随之变化 允许或拒绝后卡片给出结果 |
| 夜间时间轴 | 进入视野后循环 | 进度从夜里走到早上 三个任务依次点亮 |
| 本机与网关 | 进入视野后循环 | 小圆点沿连线移动 |
| Bot 状态点 | 持续 | 工作中的 Bot 状态点呼吸 |
| 导航栏 | 离开顶部 | 底部细线淡入 |
| 按钮 | 按下 | 缩到 0.97 |
| 主题切换 | 点击 | 颜色 0.4 秒过渡 |

## 约束

- 只动 `opacity` `translate` `scale` `rotate` `clip-path`
- 系统开启 减少动态效果 时全部关闭 场景直接显示完成态
- 没有 JS 时内容照常可见 隐藏态只在 `html.motion` 下生效

## 文件

- `styles/motion.css` 全部动效
- `scripts/bots.js` Bot 形象的生成与状态动作 只给屏幕内且非静止的 Bot 逐帧更新
- `scripts/motion.js` 场景进入视野时加 `.play` 审批场景的点击逻辑
- 给元素加 `data-scene` 即参与进入视野播放
